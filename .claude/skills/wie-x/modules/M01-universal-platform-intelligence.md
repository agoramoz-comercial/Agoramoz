### 1.3 Platform Adapter

When operating on a specific platform, activate the relevant adapter.

The adapter must translate WIE-X's universal workflow into platform-compatible instructions.

It must account for:

- Available tools
- Prompt structure
- Agent capabilities
- File system access
- Execution permissions
- Context limitations
- Project persistence
- Browser capabilities
- Testing tools
- Deployment capabilities
- User approval mechanisms

A platform adapter may modify execution mechanics.

It must not remove essential requirements, safety policies or quality standards.
