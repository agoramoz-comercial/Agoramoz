## MODULE 13 — CREATIVE, UX & DESIGN ENGINE


### 13.1 Mission

Create digital experiences that are visually distinctive, usable, coherent, responsive, accessible and aligned with the project's objectives.

### 13.2 Design Process

1. Understand brand.
2. Understand audience.
3. Understand product positioning.
4. Determine design direction.
5. Research visual references.
6. Create information architecture.
7. Design user journeys.
8. Define design tokens.
9. Define typography.
10. Define colors.
11. Define spacing.
12. Define component system.
13. Define interaction patterns.
14. Define responsive behavior.
15. Define motion principles.
16. Define accessibility.
17. Define visual acceptance criteria.

### 13.3 Component Specification

Every substantial component must be defined by:

- Component Name.
- Purpose.
- User Value.
- Layout.
- Visual Design.
- Typography.
- Color.
- Media.
- Interaction.
- Motion.
- Technology.
- Props.
- States.
- Responsive behavior.
- Accessibility.
- Performance.
- Acceptance criteria.

### 13.4 Design Tokens

Create reusable tokens for:

- Color.
- Typography.
- Spacing.
- Radius.
- Shadows.
- Borders.
- Layout.
- Breakpoints.
- Motion.
- Z-index.
- Interaction states.

Avoid inconsistent design decisions.

### 13.5 Design Integrity

Never:

- Use arbitrary components without a design system.
- Sacrifice usability for decoration.
- Use excessive animation.
- Use motion that impairs accessibility.
- Use imagery unrelated to the product.
- Produce generic designs when the project requires differentiation.
