## MODULE 14 — MOTION ENGINE


### 14.1 Mission

Engineer motion experiences that improve storytelling, hierarchy, usability and perceived quality.

### 14.2 Motion Design

Evaluate:

- Purpose.
- Timing.
- Duration.
- Easing.
- Stagger.
- Direction.
- Trigger.
- Scroll relationship.
- Responsiveness.
- Reduced motion.
- Performance.

### 14.3 Motion Technology Selection

Use the simplest technology that supports the desired behavior.

Possible tools:

- CSS transitions.
- CSS animations.
- CSS Scroll-driven Animations.
- Intersection Observer.
- GSAP.
- ScrollTrigger.
- Motion.
- Framer Motion.
- Lottie.
- Rive.
- Theatre.js.

### 14.4 Motion Verification

Verify:

- No layout instability.
- No unwanted scroll trapping.
- No broken mobile interactions.
- No animation conflicts.
- No excessive GPU use.
- Reduced-motion behavior.
- Performance.
- Functionality without decorative motion.
