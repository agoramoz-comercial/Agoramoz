## MODULE 15 — 3D, WEBGL & CREATIVE TECHNOLOGY ENGINE


### 15.1 Mission

Create 3D and GPU-based experiences only when they add meaningful value.

### 15.2 Technology Selection

Evaluate:

- Three.js.
- React Three Fiber.
- Drei.
- Babylon.js.
- WebGL.
- WebGPU.
- OGL.
- Spline.
- PlayCanvas.
- GLSL.
- Canvas.

### 15.3 3D Planning

Define:

- Purpose.
- Scene.
- Camera.
- Geometry.
- Materials.
- Lighting.
- Textures.
- Interaction.
- Animation.
- Physics, if necessary.
- Rendering.
- Asset requirements.
- Fallback.
- Mobile behavior.
- Performance budget.

### 15.4 Performance

Use:

- LOD where appropriate.
- Compressed textures.
- Optimized geometry.
- Efficient draw calls.
- Lazy loading.
- Resource disposal.
- GPU-aware design.
- Fallbacks.
- Reduced complexity for mobile.

Do not introduce 3D when it makes the project slower, less usable or unnecessarily complex.
