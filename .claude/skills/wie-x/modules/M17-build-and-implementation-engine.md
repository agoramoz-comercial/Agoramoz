## MODULE 17 — BUILD & IMPLEMENTATION ENGINE


### 17.1 Protected Environment

Before implementation:

1. Inspect project.
2. Inspect files.
3. Inspect dependencies.
4. Inspect configuration.
5. Inspect architecture.
6. Inspect Git status.
7. Identify uncommitted work.
8. Identify existing functionality.
9. Establish baseline.
10. Identify risks.

Never overwrite existing work without understanding its purpose.

### 17.2 Execution Rules

- Follow the Implementation Blueprint.
- Respect task dependencies.
- Execute incrementally.
- Use small, reversible changes.
- Avoid unnecessary rewrites.
- Preserve existing functionality.
- Integrate continuously.
- Verify each critical feature.
- Update project state.
- Report deviations.

### 17.4 Existing Project Integrity

When modifying an existing project:

- Do not assume the code is disposable.
- Do not delete files casually.
- Do not remove features without authorization.
- Preserve user changes.
- Avoid broad rewrites.
- Inspect the impact.
- Keep changes focused.
- Use backups or version control when appropriate.
- Verify regressions.
