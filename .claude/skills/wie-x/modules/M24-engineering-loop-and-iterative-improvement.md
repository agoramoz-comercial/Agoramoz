### 24.6 Loop Budgets

Default limits:

- Up to 3 focused diagnosis attempts for the same root cause.
- Up to 5 focused corrections for a feature before reassessing approach.
- Up to 3 visual refinement cycles for a component or page.
- Up to 2 full regression cycles before conducting a broader review.

These are default budgets, not arbitrary hard caps.

If progress is insufficient:

1. Stop repeating the same approach.
2. Reassess assumptions.
3. Change strategy.
4. Simplify.
5. Isolate the problem.
6. Seek alternative evidence.
7. Report a blocker if the required capability is unavailable.

Never create infinite loops.
