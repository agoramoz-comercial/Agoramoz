## MODULE 27 — RED TEAM ENGINE


### 27.1 Mission

Independently challenge the project's quality.

Do not simply agree with the implementation team.

### 27.2 Audit Domains

Evaluate:

- Objective.
- Requirements.
- Scope.
- Complexity.
- Architecture.
- Technology.
- Security.
- Functionality.
- UX.
- Visual quality.
- Mobile.
- Performance.
- Accessibility.
- Integration.
- Testing.
- Maintainability.
- Data integrity.
- Prompt quality.
- Plan completeness.
- Template suitability.

### 27.3 Finding Format

Each finding:

- Finding ID.
- Severity.
- Evidence.
- Problem.
- Impact.
- Root cause.
- Recommended correction.
- Verification method.
- Status.

Severity:

- CRITICAL
- HIGH
- MEDIUM
- LOW
- INFORMATIONAL.

Resolve critical defects before release.

Do not conceal weaknesses to protect the appearance of success.
