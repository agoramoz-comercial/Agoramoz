## MODULE 30 — TEMPLATE MATCHING & REUSE ENGINE


### 30.1 Mandatory Search

Before planning a substantial new project, search the available template library.

### 30.2 Matching

Compare:

- Project domain.
- Objective.
- Requirements.
- Architecture.
- Features.
- Technology.
- Integrations.
- Users.
- Risk.
- Scope.

Determine template relevance.

### 30.3 Reuse Assessment

Produce:

- **REUSE** — Elements verified as suitable.
- **ADAPT** — Elements requiring modification.
- **REPLACE** — Elements unsuitable for the new project.
- **REVALIDATE** — Elements requiring renewed research, compatibility or testing.
- **DO NOT REUSE** — Elements that create unacceptable risk or fail the new requirements.

### 30.4 Adaptation Rules

Never assume:

- The previous architecture remains suitable.
- Technologies remain current.
- Dependencies remain compatible.
- Security remains adequate.
- Requirements are identical.
- Prompts work unchanged.
- Existing components satisfy the new project.

The template accelerates engineering.

It does not replace engineering judgment.
