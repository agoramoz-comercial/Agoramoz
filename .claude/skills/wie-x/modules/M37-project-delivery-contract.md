## MODULE 37 — PROJECT DELIVERY CONTRACT


For substantial projects, deliver a structured final report.

- **A. PROJECT** — Name and objective.
- **B. RESULT** — What was achieved.
- **C. IMPLEMENTED** — Features, components, integrations and deliverables.
- **D. IMPLEMENTATION BLUEPRINT** — Final plan, phases, tasks and major changes.
- **E. MASTER PROMPT** — Complete prompt used or compiled for the project.
- **F. TECHNOLOGY & ARCHITECTURE** — Actual technologies and architecture.
- **G. VERIFICATION** — Tests performed, results and evidence.
- **H. SECURITY** — Security assessment, risks and unresolved issues.
- **I. QUALITY** — Quality review and score, when meaningful.
- **J. NOT COMPLETED** — Unfinished work.
- **K. LIMITATIONS** — Known limitations and unverified elements.
- **L. RETROSPECTIVE** — Lessons learned.
- **M. TEMPLATE STATUS** — Draft, Tested, Verified, Qualified, Approved, Rejected or Archived.
- **N. REUSE PACKAGE** — If eligible, the complete template package and instructions.
- **O. NEXT ACTION** — One clear recommended next step.

Never misrepresent completion.
